# Excel Data Analysis – PivotTables, Slicers, PivotCharts & Data Cleaning

## 📊 Overview

This project contains my practical Excel exercises focused on preparing, analyzing, and visualizing data.

The main topics covered are:

* Data Cleaning
* PivotTables
* Slicers
* PivotCharts
* Product analysis
* Category analysis
* Quantity analysis
* Sales analysis

## 🧹 1. Data Cleaning

Before performing analysis, I practiced preparing raw data for use in Excel reports.

The cleaning process included checking the dataset for issues and making the data consistent and analysis-ready.

## 📊 2. PivotTables

I used PivotTables to summarize the dataset and analyze:

* Product
* Category
* Quantity
* Sales

PivotTables helped me quickly compare different groups and understand the overall performance of the dataset.

## 🎛️ 3. Slicers

I practiced using Slicers to make the PivotTable analysis interactive.

I used Slicers to filter the analysis based on fields such as:

* Product
* Category

I also practiced changing the Slicer layout to display items in a vertical list.

## 📈 4. PivotCharts

I created PivotCharts based on the PivotTable analysis to visualize the data.

This helped me understand how interactive filters can affect charts and make reports easier to analyze.

## 🔄 Analysis Workflow

```text
Raw Data
   ↓
Data Cleaning
   ↓
PivotTable
   ↓
Slicer
   ↓
PivotChart
   ↓
Interactive Analysis
```
